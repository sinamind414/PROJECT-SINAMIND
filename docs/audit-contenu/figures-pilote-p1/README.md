## Méthode

- Générées depuis les specs du cours (sections 🗺️, 196-363 caractères —
  contenu, code couleur, éléments attendus).
- **Sans étiquettes arabes** : la génération d'images rend mal le texte
  arabe (caractères cassés). Les étiquettes + légende type Bac
  (« Document 1 : … ») s'ajoutent en surimpression vectorielle lors de la
  relecture — c'est l'étape à l'étape 3 du pipeline.
- Labels latins/ chimie autorisés (CO₂, ATP, NADPH, G3P…) — rendus
  correctement.

   3AS validé dès archivage de la pièce source).
2. ☐ Étiquettes arabes ajoutées (surimpression vectorielle) + légende type
   Bac « Document 1 : … ».
3. ☐ Détails spécifiques au point « à traiter » ci-contre.
4. ☐ Lisibilité imprimée A4 (épaisseur des traits, contraste).
5. ☐ Décision : **ACCEPTER / AMENDER (préciser) / REJETER** — signature + date.
